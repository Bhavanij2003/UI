# BinaryWorks Housekeeping Audit: mobile UI

Vite project (vanilla JS, no framework).

    npm install
    npm run dev       # local preview
    npm run build     # outputs dist/

Deploy on Vercel: import the folder, framework preset Vite (build `npm run build`, output `dist`).

## Structure
- index.html: page shell
- src/styles.css: all styles and theme variables
- src/app.js: screens, state and data
- src/main.js: entry
